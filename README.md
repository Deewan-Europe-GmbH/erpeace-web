# ERPeace website (erpeace.com)

Plain HTML site for erpeace.com, hosted on Netlify. Every change pushed to `main` goes online automatically.

- `index.html` front page, `impressum.html`, `privacy.html`
- `consent.js` cookie banner: content from other companies loads only after "Allow all" (see comment in the file for how to embed)
- `style.css` midnight colours
